# Type Attack Chart

There are a total of 17 different types currently in the Pokemon games (and its been confirmed that Diamond/Pearl will not add any more to that). However, some types easily outbeat other types while some barely nick others. Use the type chart here to determine what attacks are (not) effective against other types.
